Otomo Tools — install
=====================

Requires REFramework (dinput8.dll) for Monster Hunter Wilds.

1. Copy otomo_tools.lua into:
       <game>\reframework\autorun\otomo_tools.lua

2. In game, press Insert (REFramework menu) -> Script -> Reset scripts.
   A Lua error in re2_framework_log.txt means the file did not load; check
   that the file is byte-identical to the repo copy.

3. Insert -> Script Generated UI -> "Otomo Tools v0.3.1".

Settings are saved to <game>\reframework\data\otomo_tools.json the first time
you change something in the panel.

What it does
------------
The Palico's support moves have cooldowns stored as plain data. The Attack-Up
horn ships with a 600-second cooldown (10 minutes), which is why it is so rare.
This mod rewrites those numbers for the tools you pick — the default preset
takes the horn to 90 seconds.

Enable it in the hub if you can: the game copies these values into the Palico
when a quest starts, so a hub change applies from the next quest.

Nothing is triggered, hooked or animated — it is a data edit.

Uninstall
---------
Delete otomo_tools.lua from reframework\autorun\. Optionally delete
reframework\data\otomo_tools.json.

Press "Restore original cooltimes" before removing the file if you want the
shipping values back in this session; the game reloads the data on restart
anyway.
